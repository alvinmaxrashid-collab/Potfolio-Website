# Personal Portfolio Website

A responsive portfolio for Abdul Cadri Rashid, built with HTML5, CSS3, Bootstrap 5, and JavaScript.

## Pages

- `index.html` — landing page with hero section, intro cards, and call-to-action.
- `about.html` — biography, education timeline, and skill overview.
- `gallery.html` — personal gallery and project highlights.
- `contact.html` — contact information and validated form.
- `assets/style.css` — custom styling and responsive layout system.
- `assets/script.js` — year update, navbar effect, and client-side form validation.

## Run locally

1. Open the project folder in VS Code.
2. Use the Live Server extension, or open `index.html` directly in a browser.
3. Navigate through the portfolio pages from the navigation bar.

This portfolio reflects the personal profile of Abdul Cadri Rashid and includes the current GitHub, LinkedIn, and email contact details for the site.
